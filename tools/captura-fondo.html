Los porcentajes (18% 42%, 14% 38%, 22% 48%) marcan dónde cae la transición. Recarga la página para deshacerlo.

2 · Scroll uniforme para vídeo

Hace un desplazamiento suave y constante de toda la página (30 s) para grabar el fondo en movimiento. No uses el botón anterior con este: aquí quieres que el leopardo se anime.

🎬 Scroll uniforme

Cambia 30000 (milisegundos) por más para ir más lento. Pon la ventana a pantalla completa antes de grabar (Cmd+Shift+F en Chrome).

1 · Congelar fondo

(() => {
  // Congela animaciones CSS + ScrollTrigger
  const s = document.createElement('style');
  s.textContent = `*,*::before,*::after{animation-play-state:paused!important;transition:none!important}`;
  document.head.appendChild(s);
  if (window.ScrollTrigger) ScrollTrigger.getAll().forEach(t => t.kill());

  // Asienta el leopardo a su estado final (manchas formadas, tile 800px,
  // opacidad arriba) sin depender del scroll. Gancho expuesto por scripts.js.
  // Fallback: __leopardPause solo congela en el estado en que esté.
  window.__leopardSettle ? window.__leopardSettle()
                         : (window.__leopardPause && window.__leopardPause());

  // El fondo fijo pasa a cubrir TODO el documento
  const bg = document.getElementById('site-bg');
  if (bg) {
    bg.style.position = 'absolute';
    bg.style.height = document.documentElement.scrollHeight + 'px';
  }

  // Recrea el "scroll" como degradado vertical en la imagen
  const leo = document.getElementById('bg-leopard');
  const mask = (el, grad) => { if (!el) return; el.style.webkitMaskImage = grad; el.style.maskImage = grad; };
  if (leo) leo.style.opacity = 0.9;
  mask(leo, 'linear-gradient(to bottom, transparent 0%, transparent 18%, black 42%)');
  const blobs = document.querySelector('.bg-blobs');
  mask(blobs, 'linear-gradient(to bottom, black 0%, black 14%, transparent 38%)');
  const tint = document.querySelector('.bg-tint');
  if (tint) tint.style.opacity = '1';
  mask(tint, 'linear-gradient(to bottom, transparent 0%, transparent 22%, black 48%)');
})();

2 · Scroll uniforme

(() => {
  const dur = 30000; // ms en recorrer toda la página
  const end = document.documentElement.scrollHeight - window.innerHeight;
  const t0 = performance.now();
  (function step(t) {
    const p = Math.min((t - t0) / dur, 1);
    window.scrollTo(0, end * p);
    if (p < 1) requestAnimationFrame(step);
  })(t0);
})();
